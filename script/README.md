# Execution Scripts for Reproducibility 

The R script collected in this folder allows the entire reproduction of all the numbers and figures shown in "_Bayesian Transfer Learning for Artificially Intelligent Geospatial Systems: A Predictive Stacking Approach_". Here, a brief reminder of which script is needed to reproduce the contents of a specific Section is presented to ease the reproducibility. Reminding the Workflow on the main `README.md` of this repository, for an exhaustive and detailed approach to reproduce the results.

* Section 5.1: [`Predictive_coverage_simulation.R`](Predictive_coverage_simulation.R)
* Section 5.2: [`Transfer_learning_simulation.R`](Transfer_learning_simulation.R)
* Section 5.3: [`Amortized_bayesian_inference_simulation.R`](Amortized_bayesian_inference_simulation.R)
* Section 6: [`Vegetation_data_analysis.R`](Vegetation_data_analysis.R)
* Appendix Section C.1: [`Computational_performance_simulation_1.R`](Computational_performance_simulation_1.R), [`Computational_performance_simulation_2.R`](Computational_performance_simulation_2.R)
* Appendix Section C.2: [`Upperbound_simulation.R`](Upperbound_simulation.R)
* Appendix Section C.3: [`Subset_sensitivity_simulation.R`](Subset_sensitivity_simualtion.R)
